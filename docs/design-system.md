# Career Atelier — v0.4

Three task areas: Moja kariera, Stwórz CV, Moje dokumenty. Account settings live in the account menu. Career history uses an expandable editorial timeline backed by relational data. Setup is a separate five-step space. CV editing uses controls beside a document preview, with mobile preview/edit tabs.

Tokens: Midnight Ink #172637, Jade #087F76, Periwinkle #8AA6DE, Apricot #E29B83, Warm Paper #F3F0E9. Accent tints are decorative; body text uses contrasting semantic ink. System sans interface + editorial serif headings, no remote font dependency. Shared token definitions are in styles/tokens.css; responsive layouts, visible focus and reduced-motion overrides live in app/globals.css.

Calculated contrasts: Ink/Paper13.48:1; muted #596677/Paper5.14:1; white/Jade4.88:1; jade text #075E57 on #E3EDE8 6.39:1; info #3B568A on #E7EDF9 6.20:1; violet #5C527E on #ECEAF3 5.95:1. These checks cover the selected text pairs, not a claim of a complete WCAG audit.

No invented completion percentages or quality scores. Evidence status distinguishes partial/missing evidence from lack of ability. Document templates remain Executive Clarity and Modern Studio; interface styling does not silently change the supplied document identities.
